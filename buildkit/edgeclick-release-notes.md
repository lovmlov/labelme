基于 Labelme 7.9.1 的 Windows x64 定制版，应用版本为 `7.9.1+edgeclick.1`。

下载 `.exe` 后可直接运行，无需安装 Python；`.zip` 包含同一 EXE、使用说明、许可证、源码提交号、依赖清单和测试报告。

改动：

- 在编辑模式下，默认单击多边形或折线的边缘即可新增点，无需按住 Alt；原有 Alt+单击仍可使用。
- 新增点后可以继续按住鼠标拖动，支持撤销、保存和重新打开。
- 设置窗口的“绘图和画布”分组新增“单击边缘新增点（无需 Alt）”开关，修改后立即生效并保存。
- 保留 Ctrl/Shift 操作、现有顶点拖动和锁定标注的保护；Alt+Shift+单击删除顶点的行为不变。
- 更新简体和繁体中文的状态提示与设置说明。

也可在 `%USERPROFILE%\.labelmerc` 中合并以下配置（不要重复已有的 `canvas:` 段）：

```yaml
canvas:
  add_point_on_edge_without_alt: true
```

设为 `false` 可恢复为必须按 Alt 才能单击边缘加点。旧配置文件没有该项时默认启用。

构建流程先运行鼠标交互、设置、画布和配置回归测试，再启动生成的 Windows EXE，验证边缘单击加点、撤销、Alt 兼容、中文资源、图片读取及 JSON 保存重开。包内附 `windows-tests.xml` 和 `smoke-test.json`。

AI 辅助功能沿用 7.9.1；相应模型首次使用仍需下载。本次没有验证 AI 模型推理。本程序是定制打包版本。
