基于 Labelme 7.9.1 的 Windows x64 定制版，应用版本为 `7.9.1+exit.1`。

本版保留单击边缘新增点、工具栏拖动浮动、按钮拖动排序及布局保存功能；文件/编辑/视图/帮助菜单栏继续固定。

关闭流程的改动：

- 主窗口成功关闭后，明确结束应用事件循环，避免其他顶层辅助窗口使程序继续运行。
- 退出前停止 AI 预览和选区缩放定时器，释放点提示及文本提示的 AI 会话缓存。
- 事件循环结束后刷完日志队列并关闭本程序创建的日志线程，恢复原来的 Qt 日志处理器。
- Windows 独立程序使用 Job Object 将派生子进程绑定到 GUI 进程的生命周期；正常保存、任务清理与日志完成后，操作系统回收遗留子进程。
- 原有保存等待、未保存提示和下载任务退出逻辑继续生效；选择取消不会退出程序。

验证流程：源码回归测试；实际 EXE 的标注读写及工具栏自检；正常关闭、浮动工具栏、打开设置/模型窗口、额外顶层窗口、自动保存、取消后再次关闭、受控子进程共 7 种完整退出场景；默认及浮动布局的 Windows 原生 WM_CLOSE 验证。外部观察器检查 PyInstaller 父进程和 GUI/派生子进程均退出，失败后用于清场的强制结束不计为通过。

这是对退出生命周期的修复及防护；旧版在所有电脑上的后台驻留原因并未由此一概确定。没有进行真实 AI 模型下载或推理验证，模型会话释放使用受控资源测试。

ZIP 附带使用说明、GPL 许可证、依赖、源码提交、Windows 回归报告、EXE 自检和完整退出报告。下载 EXE 可直接运行，无需安装 Python；AI 模型仍按需下载。本程序为定制版本。
