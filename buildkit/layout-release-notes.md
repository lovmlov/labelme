基于 Labelme 7.9.1 的 Windows x64 定制版，应用版本为 `7.9.1+layout.2`。

本版保留上一版的“单击边缘新增点”功能，并恢复可拖动的工具栏布局。下载 EXE 后可直接运行，无需安装 Python。

改动与操作：

- 工具栏整体移动：按住工具栏边缘的拖动手柄，拖到窗口上、下、左、右侧，也可拖入画布区域成为浮动工具栏。
- 操作按钮布局：直接按住按钮并拖动，可以在本工具栏内排序，也可移到另一条工具栏；拖动时显示插入位置。单击仍执行原操作，拖动不会触发按钮操作，灰色按钮也可调整。
- “文件 / 编辑 / 视图 / 帮助”菜单栏继续固定在顶部，其菜单内容与顺序保持原有设置。
- 关闭程序后保存工具栏位置和按钮顺序，重新启动自动恢复；切换界面语言也保留布局。
- 使用“视图 → 重置布局”可同时恢复工具栏位置和按钮默认顺序。
- 横向、纵向切换时重新适配按钮宽度；AI 输入框、模型选择及缩放控件保留在原工具栏，可正常使用。
- 默认左键单击多边形/折线边缘新增点，Alt+单击仍可用；原配置 `canvas.add_point_on_edge_without_alt` 继续生效。

验证范围：工具栏真实手柄拖动与浮动、四个停靠方向、按钮鼠标拖动与跨工具栏移动、防误触、菜单栏固定、关闭重开、重置布局、异常布局数据，以及原有标注交互回归。构建后还会启动实际 EXE 进行布局和标注读写自检。

ZIP 包含同一 EXE、使用说明、GPL 许可证、依赖清单、源码提交号、`windows-tests.xml` 和 `smoke-test.json`。本次未验证 AI 模型推理；人工标注无需下载模型，AI 辅助功能的模型权重按需下载。本程序为定制打包版本。
